# visuals/ — 근육 피로도 이미지

> **담당**: #5 시각화·UX 슬라이스

## 진입점

```python
def render_fatigue(state: MuscleFatigueState) -> bytes:  # PNG
```

`state.fatigue` 예: `{"가슴": 3, "등": 1, "하체": 4, "어깨": 0, "코어": 2, "이두": 1, "삼두": 2}` (값 0~5)
반환은 PNG 바이트. Streamlit에서 `st.image(render_fatigue(state))`로 바로 표시.

## 구현 단계

1. **1차 (5/4~5/6)**: Pillow로 인체 실루엣 PNG/SVG 위에 부위별 색상 오버레이 합성
   - 부위 → 좌표/마스크 매핑 테이블 (`MUSCLE_REGIONS`)
   - 0=초록, 3=노랑, 5=빨강 (그라데이션)
2. **2차 (시간 남으면)**: 이미지 모델 호출 (DALL-E 등)로 더 풍부한 시각화

## 운동 → 부위 매핑 (Agent 측 로직과 일관성 유지)

```python
WORKOUT_TO_MUSCLES = {
    "헬스(가슴)": ["가슴", "삼두"],
    "헬스(등)": ["등", "이두"],
    "헬스(다리)": ["하체"],
    "러닝": ["하체", "코어"],
    "홈트(스쿼트)": ["하체", "코어"],
    ...
}
```

이 매핑은 `nodes.py`의 스케줄 도출 로직과 **동일한 키**를 사용해야 한다. 새 운동 추가 시 두 군데 모두 갱신.

## 작업 시 주의

- 한 번 그린 이미지는 캐시 (`@st.cache_data` 또는 LRU). 같은 state 입력은 같은 PNG.
- 인체 실루엣 에셋은 `visuals/assets/`에 두기 (없으면 만들 것)
- 색맹 친화 팔레트 권장 (빨/초 단색 대신 채도 변화)
